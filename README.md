# Site Institucional para o Laboratório de Neuroquímica e Biologia Celular

Repositório do site institucional desenvolvido para apresentar informações, projetos, publicações e integrantes da organização de forma moderna, responsiva e acessível.

##  Sobre o projeto

Este projeto consiste no desenvolvimento de um website institucional com foco em **organização das informações, responsividade e experiência do usuário**.

O site foi desenvolvido para funcionar em computadores, tablets e dispositivos móveis, utilizando tecnologias web amplamente utilizadas no desenvolvimento front-end.

##  Tecnologias utilizadas

* **HTML5** — estrutura e organização das páginas
* **CSS3** — estilização e responsividade
* **JavaScript** — interações e funcionalidades
* **Bootstrap** — componentes e sistema de grid responsivo
* **SVG** — elementos gráficos e ilustrações
* **Font Awesome** — ícones e redes sociais
* **Python** — Scraper 
* **Json** — Dados

##  Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/baike97/labnq_site.git
```

### 2. Entre na pasta do projeto

```bash
cd SEU-REPOSITORIO
```

### 3. Execute o site

Por ser um projeto desenvolvido com HTML, CSS e JavaScript, não é necessário instalar dependências para executá-lo.

Você pode abrir diretamente o arquivo:

```text
Html/index.html
```

ou utilizar uma extensão como **Live Server** no Visual Studio Code.
